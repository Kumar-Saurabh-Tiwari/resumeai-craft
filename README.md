AI Resume Creator & Analyzer
An intelligent web application that helps job seekers build professional resumes and optimize them for Applicant Tracking Systems (ATS) using AI.

Key Features
AI Resume Builder: Create polished, professionally phrased resumes from scratch.

ATS Optimization Score: Match your resume against a job description to get an instant compatibility score (0-100%).

Skill Gap Analysis: Automatically spot missing keywords and get AI recommendations to fix them.

One-Click Export: Download clean, ATS-friendly resumes instantly as a PDF.

Tech Stack
Frontend: HTML5, CSS3, JavaScript

AI Engine: OpenAI / Gemini API for intelligent text analysis and tailoring.
